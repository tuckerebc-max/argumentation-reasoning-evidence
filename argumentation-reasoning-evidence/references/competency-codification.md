# Argumentation competency codification

**Competency:** `COMP-ARG-REASONING`  
**Domain:** `DOM-ARG` / `SKILL-ARG`  
**Governing protocol:** `SPEC-COMP-001`  
**Technical specification:** `SPEC-ARG-001`  
**Prompt:** `ANRI-DOM-ARG-001`  
**Architecture:** `ARCH-ARG-001`  
**Corpus:** `CORP-ARG-001`

## Construct

Construct, interpret, evaluate, and revise reasons offered for a claim under a declared question, audience, mode, burden, and evidence standard. Make claims, reasons, evidence, warrants, qualifiers, alternatives, objections, and response logic inspectable while respecting the people and institutions involved.

## Observable performances

| ID | Performance |
|---|---|
| `OP-ARG-01` | Identify question at issue, controversy, audience, mode, and burden. |
| `OP-ARG-02` | State a bounded claim and distinguish it from reasons and evidence. |
| `OP-ARG-03` | Test warrants, backing, qualifiers, and rebuttal conditions. |
| `OP-ARG-04` | Evaluate source authority, evidence quality, relevance, and uncertainty. |
| `OP-ARG-05` | Represent a strongest alternative fairly and answer it proportionately. |
| `OP-ARG-06` | Adapt construction and response to the declared format. |
| `OP-ARG-07` | Revise or suspend a claim when evidence or reasoning fails. |
| `OP-ARG-08` | Preserve learner decisions, provenance, and ethical participation in AI-assisted work. |

## Functional-requirement trace

| ID | Canonical requirement and acceptance focus |
|---|---|
| `FR-ARG-01` | Contract rhetorical situation, issue, audience, purpose, mode, constraints, and burden before drafting. |
| `FR-ARG-02` | Classify the question as fact, value, policy, definition, interpretation, or mixed; burden and evidence plan branch accordingly. |
| `FR-ARG-03` | Build a dispute/stasis map with definitions, agreement, disagreement, affected parties, and options. |
| `FR-ARG-04` | Represent claim, reason, evidence, warrant, backing, qualifier, rebuttal, and dependency relations. |
| `FR-ARG-05` | Use Toulmin components as a local reasoning diagnostic, not as universal argument validation. |
| `FR-ARG-06` | Name and test an appropriate inference or argument scheme when useful. |
| `FR-ARG-07` | Maintain an evidence ledger with direct locators, source claims, relevance, limitations, and provenance. |
| `FR-ARG-08` | Evaluate source quality, currency, method, incentives, corroboration, and uncertainty relative to the claim. |
| `FR-ARG-09` | Require a strongest alternative and a learner-selected response: rebut, concede, qualify, revise, withdraw, or unresolved. |
| `FR-ARG-10` | Support written argument, spoken debate, dialogic deliberation, and multimodal performance as different modes. |
| `FR-ARG-11` | Separate persuasive effectiveness, epistemic support, source practice, dialectical quality, and participation ethics. |
| `FR-ARG-12` | Provide feedback that identifies effect, reason, question/option, and next decision. |
| `FR-ARG-13` | Preserve learner authorship in graded, AP, and course work through scaffolds and checkpoints. |
| `FR-ARG-14` | Track accessibility, language variation, participation power, and delivery conditions. |
| `FR-ARG-15` | Export a transfer record to Close Reading, Writing, QUEST, and later Public Argument Resolution. |
| `FR-ARG-16` | Enforce source rights, versioning, and currentness before released use. |
| `FR-ARG-17` | Disclose AI use and distinguish generated suggestions from learner-authored decisions. |

## Project diagnostic dimensions

Issue fit; claim scope; reason/evidence quality; warrant adequacy; source/provenance integrity; alternative representation; objection response; burden/standard fit; adaptation to mode; delivery/participation where relevant; revision; and authorship transparency are project-defined unless a named standard, course, or format supplies an official criterion.

## Source and assessment boundaries

The authority stack includes Common Core (`S003/S006`), AP English Language (`S105`), GRE/ACT (`S106/S108`), LSAT (`S107`), Smarter Balanced/PARCC (`S101/S100`), Texas Debate (`S059`), WUDC (`S078`), Toulmin/Zarefsky (`S041/S042`), open instructional treatments (`S039/S040`), empirical/context research (`S045-S058`), and bounded expansion comparators (`S132`, `S133`, `S135`). These sources describe distinct standards, theories, tasks, or modes; none creates a universal argument score.

## Evidence and release conditions

Each task declares `WRITTEN_ARGUMENT`, `SPOKEN_DEBATE`, `CLASSROOM_DISCUSSION`, `RESEARCH_ARGUMENT`, or `PUBLIC_ARGUMENT`, plus issue, audience/authority, claim type, burden, source set, time/turn constraints, and response rules. `TST-ARG-001` through `TST-ARG-016`, `TST-INT-006`, and `TST-INT-007` are required. Open conditions include current format specifications, separate evidence for dialogue/debate/writing transfer, human review of public handoffs, and rights-cleared exemplars.
